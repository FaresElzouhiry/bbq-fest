# BBQ FEST — الموقع والمخطط ثلاثي الأبعاد

موقع مهرجان **BBQ FEST** (الرياض · 19–23 يناير) بثلاث تصاميم مختلفة تختار منها، ومعاهم مخطط ثلاثي الأبعاد للمهرجان: الأرض الفاضية، ثم المخطط مفروش عليها، ثم المهرجان مجسّمًا، مع وضع تجوّل تمشي فيه جوّه المهرجان.

## الصفحات

| الملف | المحتوى |
|---|---|
| `index.html` | **الرابط الأساسي = موديل 3 «الجولة»**: المشهد الـ 3D مالي الشاشة والكاميرا بتتنقل بين المناطق مع التمرير، وفيه فصل «تجوّل داخل المهرجان» |
| `models.html` | صفحة الاختيار: بطاقة لكل موديل وبطاقة للمخطط ثلاثي الأبعاد (لينك «تغيير التصميم» في آخر كل موديل) |
| `model-1.html` | **جمر**: داكن سينمائي بنفس هوية العرض (أسود وأحمر) |
| `model-2.html` | **ورق الجزّار**: فاتح بطابع ورقي، أختام وتذاكر وقائمة أسعار على شكل "منيو" |
| `model-3.html` | تحويل تلقائي لـ `index.html` عشان اللينكات القديمة تفضل شغالة |
| `map-3d.html` | المخطط ثلاثي الأبعاد لوحده بملء الشاشة |

الثلاث موديلات فيهم نفس المحتوى: عن المهرجان، التجارب، البرنامج، الجمهور، لماذا ترعى، باقات الرعاية، الصور، الموقع، ونموذج الحجز.

## التشغيل

الموقع ملفات HTML عادية ومش محتاج تثبيت أي حاجة، بس **محتاج إنترنت** لأن الخطوط ومكتبة الـ 3D (Three.js) بتتحمّل من CDN.

- **أسهل طريقة:** دبل كليك على `index.html` (بيفتح موديل 3 على طول). صفحة الاختيار بين الموديلات في `models.html`.
- **سيرفر محلي:**

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

وبعدين افتح `http://localhost:5173`.

### روابط مفيدة لصفحة المخطط

| الرابط | النتيجة |
|---|---|
| `map-3d.html` | عرض تلقائي: الأرض ثم المخطط ثم المهرجان |
| `map-3d.html?stage=2` | يبدأ والمهرجان مبني (`0` الأرض، `1` المخطط، `2` المهرجان) |
| `map-3d.html?theme=night` | الإضاءة: `day` أو `sunset` أو `night` |
| `map-3d.html?walk=1` | يدخل وضع التجوّل على طول |

## التعديل

**كل المحتوى المتغيّر في ملف واحد: [`js/data.js`](js/data.js)**، وأي تعديل فيه بيظهر في الثلاث موديلات والمخطط مرة واحدة.

| عايز تغيّر | فين في `data.js` |
|---|---|
| التاريخ والعد التنازلي | `dateLabel` و `dateStart` |
| الإيميل والواتساب | `contact` |
| أسعار ومقاسات الأجنحة | `types` |
| الباقات ومزاياها وصورها | `packages` |
| التجارب والبرنامج والجمهور | `experiences`، `program`، `audience` |
| إخفاء الـ 3D جوّه المواقع | `map3dSoon: true` |

### نموذج الحجز

النموذج **مش مربوط بأي سيرفر**. لما الزائر يبعت الطلب، بيظهرله نص الطلب جاهز:
- **زر نسخ:** موجود دايمًا.
- **إرسال عبر واتساب أو بالإيميل:** الأزرار دي بتظهر بس لما تحط الرقم أو الإيميل في `contact`.

لما الزائر يضغط على جناح في المخطط ويختار "اطلب حجز"، رقم الجناح ونوع الباقة بيتملوا في النموذج تلقائيًا.

### المخطط ثلاثي الأبعاد

- **أماكن الأجنحة:** متاخدة من ملف الخريطة `bbq fest.map.pdf` ومحوّلة لأمتار في `data.js` (`booths` و `site`).
- **الإضاءة:** ألوان نهار/غروب/ليل في أول `festival3d.js` (`THEMES`).
- **جودة الموبايل:** على الموبايل المشهد بيشتغل بنسخة أخف تلقائيًا (دقة أقل بتتظبط لوحدها، 30 إطار في الثانية، ظلال أبسط، فلل وزوار أقل). الإعدادات في سطر `LQ` في أول `festival3d.js`.

## التحكم في المخطط

| | كمبيوتر | موبايل |
|---|---|---|
| **التدوير والتقريب** | اسحب بالماوس، والعجلة للتقريب | اسحب بصباع، وصباعين للتقريب |
| **تفاصيل جناح** | اضغط عليه | اضغط عليه |
| **التجوّل** | زر "تجوّل داخل المهرجان"، ثم اضغط على المشهد وحرّك الماوس للنظر زي الألعاب | زر "تجوّل داخل المهرجان"، ثم عصا التحكم للمشي واسحب الشاشة للنظر |
| **المشي** | `W A S D` أو الأسهم، و`Shift` للجري | عصا التحكم |
| **الانتقال السريع** | اضغط على الخريطة المصغّرة | اضغط على الخريطة المصغّرة |
| **الخروج** | `Esc` يحرّر الماوس، ومرة كمان تخرج من التجوّل | زر "خروج من التجوّل" |

**زر التجوّل في الموقع الأساسي** موجود في 3 أماكن: الشريط العلوي (مكتوب "تجوّل" على الموبايل)، أول الصفحة جنب "ابدأ الجولة"، وفصل مخصوص في الجولة اسمه "تجوّل داخل المهرجان". أول ما الزائر يدخل التجوّل بتظهرله بطاقة قصيرة بتشرح التحكم (على الموبايل بزر "ابدأ التجوّل"، وعلى الكمبيوتر بتختفي لوحدها). ولو دخل التجوّل من الجولة، الخروج بيرجّعه لنفس مكانه.
